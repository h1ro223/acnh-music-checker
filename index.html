このサイトについて

本サイトは、Nintendo Switch用ゲーム『あつまれ どうぶつの森』に登場するミュージシャン「とたけけ」の楽曲の所持状況を確認・管理するための非公式ファンツールです。

ゲーム内には多数の楽曲が存在しており、プレイヤーが自分のコレクション状況を把握することが難しい場合があります。本ツールは、チェック形式で楽曲の所持状況を整理・管理できるようにすることを目的として制作されています。

About This Website

This website is an unofficial fan-made tool designed to help players track and manage the songs performed by K.K. Slider in the Nintendo Switch game "Animal Crossing: New Horizons".

The game contains many collectible songs, and it can be difficult for players to keep track of which songs they have already obtained. This tool provides a checklist-style interface that allows users to organize and track their collection.
